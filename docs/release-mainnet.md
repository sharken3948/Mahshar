# Mahshar — Arc Mainnet Release

Mahshar's Arc Mainnet release introduces:

- USDC pay-per-call API execution.
- Machine-readable API discovery.
- Four upstream authentication models: public, API-key header, bearer token, and query credential.
- Durable purchase-scoped response recovery.
- Wallet-bound browser sessions with reduced signature repetition.
- Atomic seller withdrawal accounting.
- Hardened credential proxy and path/query authorization.
- Expanded marketplace security and regression testing.

See the repository [changelog](../CHANGELOG.md) for detailed changes.
